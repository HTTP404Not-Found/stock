## 1. 自選股（Watchlist） `/watchlist`

**目的**：讓使用者一眼掌握所有追蹤標的的「合理估值 vs 現價」差距。

### 版面結構

```
┌──────────────────────────────────────────────────────────┐
│ 自選股                              [+ 新增標的]         │
├──────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────┐   │
│ │ 代號     現價    合理估值   差距     信心    更新 │   │
│ │ AAPL     $182    $195     ▲ +7.1%  78%    2h前  │   │
│ │ 0700.HK  HK$345  HK$380   ▲ +10.1% 82%    1d前  │   │
│ │ TSLA     $245    $220     ▼ -10.2% 65%    3d前  │   │
│ └────────────────────────────────────────────────────�   │
│                                                          │
│ [依差距排序 ▾]  [僅顯示低估 �]  [市場：US+HK ▾]          │
└──────────────────────────────────────────────────────────�
```

### 互動元素

- **+ 新增標的** → 彈出輸入框（ticker + 市場），存到後端 watchlist API
- **點選列** → 跳轉到 `/symbol?ticker=AAPL&market=US`
- **差距顏色**：正為綠（低估）、負為紅（高估）
- **更新時間過久**（> 24h）顯示警示 icon

## 2. 個股頁（Symbol Detail） `/symbol`

**目的**：深入分析單一標的，包含基本面、技術面、預測依據。

### 版面結構

```
┌──────────────────────────────────────────────────────────┐
│ ← 返回    AAPL  Apple Inc.        US  •  USD              │
├──────────────────────────────────────────────────────────┤
│ 現價：$182.45     ▲ +1.2% (as of 14:30 EST)              │
│ 合理估值：$195.00  信心 78%   預測區間：12m               │
├──────────────────────────────────────────────────────────┤
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐         │
│ │ 基本面       │ │ 技術面       │ │ 分析師評等   │         │
│ │ PE: 28.4     │ │ MA50: 178    │ │ Buy: 24      │         │
│ │ PB: 45.2     │ │ RSI: 62      │ │ Hold: 8      │         │
│ │ Div: 0.5%    │ │ MACD: +      │ │ Sell: 2      │         │
│ └─────────────┘ └─────────────┘ └─────────────┘         │
├──────────────────────────────────────────────────────────┤
│ 📈 歷史走勢（K線圖，1y/3y/5y 切換）                      │
├──────────────────────────────────────────────────────────┤
│ � AI 預測依據                                            │
│ "EPS 增長率預估 +12% YoY，配合估值倍數擴張..."            │
│  產生模型：MiniMax-M2   產生時間：2026-08-10              │
├──────────────────────────────────────────────────────────┤
│ [加入自選股]  [重新分析]                                  │
└──────────────────────────────────────────────────────────┘
```

### 區塊說明

- **頁首**：標題列 + 即時報價 + 合理估值總覽
- **三欄卡片**：基本面、技術面、分析師評等（行動裝置上會堆疊）
- **K線圖**：可切區間（1m/3m/6m/1y/2y/5y）
- **AI 預測依據**：展開 LLM 生成的 rationale
- **動作列**：加入自選股 / 觸發重新分析

## 路由對照表（給前端）

| 路由               | 元件                  | 備註                       |
| ------------------ | --------------------- | -------------------------- |
| `/`                | `<Redirect>`          | 導向 `/watchlist`          |
| `/watchlist`       | `<WatchlistPage>`     |                            |
| `/symbol`          | `<SymbolPage>`        | 必填 query: `ticker`, `market` |
| `/settings`        | `<SettingsLayout>`    | 含 tabs：llm / data / watchlist |

## 路由對照表（給後端 API）

| Method | Path                                | 用途                  |
| ------ | ----------------------------------- | --------------------- |
| GET    | `/api/v1/watchlist`                 | 取得自選股清單        |
| POST   | `/api/v1/watchlist`                 | 加入新標的            |
| DELETE | `/api/v1/watchlist/:ticker/:market` | 移除標的              |
| GET    | `/api/v1/symbol/:ticker/:market`    | 個股完整分析          |
| GET    | `/api/v1/symbol/:ticker/:market/quote` | 即時報價            |
| GET    | `/api/v1/symbol/:ticker/:market/prediction` | 預測結果       |
| POST   | `/api/v1/settings`                  | 更新設定              |
| GET    | `/api/v1/settings`                  | 讀取設定              |
| GET    | `/api/v1/health/llm`                | 測試 LLM 連線         |
